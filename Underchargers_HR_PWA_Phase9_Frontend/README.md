# Underchargers HR PWA — Phase 9 (Frontend Only)

Complete replacement project containing Phases 1–9.

## Added in Phase 9
- Custom Filter & Reports workspace under the existing sidebar entry.
- Dynamic record/document categories, including single-instance document types.
- Filter rules (AND/OR), searchable records, reporting month and branch scoping.
- Saved presets in current component state (not persistent).
- Summary totals, employee counts, male/female salary breakdown, branch grouping.
- CSV export of filtered fictional data and browser print / Save as PDF.
- 13th-month and government compliance report interface placeholders.

All records and amounts are fabricated examples. No financial or statutory computations are certified. No Supabase backend or confidential document storage. Do not use real employee records.

## Deploy from GitHub
Extract all files from ZIP into repository root (package.json should be at root), commit, and let Vercel build. Verify build status; this package has not been production-build validated in this environment.
