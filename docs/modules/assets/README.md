# Assets & Devices

The browser-local asset inventory supports branch-scoped status filtering and clickable row details. Action forms and history are presented in portaled dialogs rather than inline below the table. Assignment, return and inspection retain existing state machines and validations. Only selected file names are stored for print evidence; a verified backend signing workflow does not exist.
